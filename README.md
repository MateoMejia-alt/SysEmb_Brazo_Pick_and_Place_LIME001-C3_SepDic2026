## Descripción general
El proyecto consiste en desarrollar un brazo robótico Pick and Place
para sujetar objetos pequeños y trasladarlos de una posición a otra.

La estructura se fabricará mediante impresión 3D y utilizará cuatro
servomotores SG90M y dos MG996R para accionar sus articulaciones y pinza.

El microcontrolador STM32F407VGTX recibirá instrucciones por Bluetooth
desde una aplicación móvil desarrollada en MIT App Inventor y generará
las señales necesarias para controlar los servomotores.

## Objetivo general
Desarrollar un brazo robótico con estructura impresa en 3D y control
desde una aplicación móvil mediante Bluetooth, para realizar tareas
de sujeción y traslado de objetos pequeños.

## Componentes principales
- Tarjeta de desarrollo con STM32F407VGTX.
- Cuatro servomotores SG90M.
- Dos servomotores MG996R.
- Módulo Bluetooth, modelo pendiente de seleccionar.
- Fuente externa para los servomotores.
- Estructura y pinza impresas en 3D.
- Cables, conectores y elementos de unión.

## Herramientas de desarrollo
